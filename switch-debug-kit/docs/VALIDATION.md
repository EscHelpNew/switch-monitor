# Что проверено

Проверка комплекта выполнена 25 октября 2026 года на Windows с devkitA64 GCC 16.1.0 и libnx 4.12.0.

- Собраны самостоятельные receiver-demo.nro, arm-lab.nro и integer.lab без исходного репозитория игры.
- При исходной проверке извлечённого комплекта архив распакован в отдельную папку с пробелами. В копии изменены имя, папка SD и ID приложения; повторно собраны оба NRO и выполнены локальные проверки.
- Проверены конфиг и отказ от небезопасных путей/ID/имён; локальный ключ не заменяется повторной подготовкой.
- Проверены реальные сокеты клиента на localhost, данные PUT, отказ записи, STATUS, CRASH и редактирование ключа в отчёте.
- Проверены публикация NRO и сохранение прежнего образа, основной поток-владелец запуска, ошибка запуска, ожидание GAME по событию и гонка позднего RUN при выходе. Мутант прежнего worker-owned запуска отклоняется тестом.
- Отдельный профиль с нулевым title_id отклоняет запуск до системных команд.
- Нераспознанный UserChannel возвращается коду игры с сохранением владения; только kit-пакет потребляется мостом.
- Проверены ABI/ответы нативного модуля, целочисленный результат, отмена, границы, FP state и отказ writable/out-of-image модулей.
- Архив формируется по явному списку. Тест кладёт случайный приватный ключ и локальный конфиг рядом с исходниками и подтверждает, что они не попали в ZIP; попытка `../` в списке отклоняется.
- Тесты пассивного Switch Monitor также проходят: английский по умолчанию, старый конфиг без языка, сохранение выбора, переключение меню, подсказки и окна подробностей, восстановление языка после повторного запуска.
- При оформлении самостоятельного репозитория обновлены цель GAME, C API game_reload_*, аргументы запуска и маркеры протокола 2. Заново собраны оба NRO и выполнен полный tests/check.py; клиент отклоняет STATUS протокола 1.

Исходная реализация приложения 0.8.0 / ARM lab 0.2.5 прошла физические переходы между новыми процессами с проверкой digest, в том числе из живой игры и после передачи нового NRO. Эта конфигурируемая копия с протоколом 2 **не была отдельно развёрнута на консоли**: на её интеграцию и новый ярлык требуется аппаратная приёмка по INTEGRATION.md. Новый UserChannel-адаптер проверен локально. Микротест стенда не доказывает FPS или правильность иной игры.

Локальные результаты SDK-сборки и контрольные суммы помещаются в build/sha256.json, который не входит в исходный архив. Исходные файлы и изменения при переносе перечислены в PROVENANCE.json.
